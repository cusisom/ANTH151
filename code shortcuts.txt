Use code with caution.🔍 Anatomy & Rules Explained 

1. Canvas Overrides (rankdir, nodesep, ranksep)By default, Graphviz packs layout items as closely together as possible. Inside <details> 
blocks or narrow web containers, this squishes text.rankdir=LR; flips the layout horizontally. This is highly recommended when text elements are long sentences, as it keeps charts from becoming 
infinitely vertical.nodesep and ranksep act like CSS padding rules between objects. Bumping these values up slightly clears up crowded alignment lines.

2. Clean Text Wrapping (\n and width)Graphviz 
does not automatically auto-wrap text strings inside standard nodes. If you pass a long sentence, the node box will simply stretch wide, breaking your layout width.The Break Rule: You must use \n manually 
inside labels wherever you want a line break.The Width Constraint: Setting a fixed width=2.2 forces the rendering engine to keep the boxes uniform. If text boxes vary wildly in character counts, a set width 
aligns column tracks seamlessly.

3. Distinct Styling ConfigurationsInstead of raw strings, nodes use structural properties inside brackets [ key=value ]:style="filled,dashed" creates a broken boundary outline 
(great for indicating abstract events, changing environments, or theoretical assumptions).penwidth=2 increases the outline thickness, drawing structural visual focus to major parent concepts (like your evolutionary 
ancestral roots).4. Safe Relationship AssignmentsUnlike Mermaid, which allows you to define a node and its connection in a single step (like A[Text] --> B[Text]), Graphviz requires a clean split:First, declare what 
the variable ID is and what its visual label text says.At the very bottom of your code, link the raw alphanumeric variable IDs directly using simple text syntax (NodeA -> NodeB;).
